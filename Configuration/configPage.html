Arr Calendar Settings

Adds Calendar to the navigation for every signed-in user. With Seerr Integration installed, it sits under Requests on devices with a mouse, and stays its own entry on phones and tablets. Browsers pick a change up when they next reload Jellyfin.

Sonarr

Sonarr as the Jellyfin server reaches it, including any URL base. Leave empty to show no episodes. HTTPS certificates are verified, except on private and loopback addresses (for example https://192.168.1.20:8989), where self-signed certificates are accepted.
From Sonarr's Settings, General.

Radarr

Radarr as the Jellyfin server reaches it, including any URL base. Leave empty to show no movies. The same certificate rule as Sonarr applies.
From Radarr's Settings, General.

Options

Off by default: the calendar shows what Sonarr and Radarr are watching for.
How long to wait for Sonarr or Radarr before showing the calendar without it.

Status

API keys stay on the Jellyfin server; browsers only ever receive the calendar entries. A key saved here can be read back by any administrator credential. To keep it out of Jellyfin's configuration, set ARR_CALENDAR_SONARR_API_KEY_FILE or ARR_CALENDAR_RADARR_API_KEY_FILE (or the same names without _FILE) in Jellyfin's environment instead.
